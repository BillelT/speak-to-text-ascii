# ASCII Speak

Voix → grille de grains. Voir `00-overview.md` à `03-claude-code-brief.md` pour le brief complet.

## Lancer

```
npm install
npm run dev
```

Parlez (ou utilisez le champ texte si le micro est indisponible). Chaque phrase
se dessine en grains, tient une seconde, puis s'effondre comme du sable.

`D` (ou l'icône en bas à droite) ouvre le debugger : réglages du shader en
direct + vue 3D orbitable pour inspecter la chute.
